# Benutzerhandbuch: CMS des Fördervereins CJD Kita Thorrfalken

> Dieses Handbuch richtet sich an Vereinsmitglieder ohne technische Kenntnisse.
> Alles, was Sie benötigen: ein Webbrowser und Ihre Anmeldedaten.

---

## 1. Anmelden im CMS

1. Öffnen Sie Ihren Browser und navigieren Sie zu:
   ```
   https://foerderverein-thorrfalken.de/admin/
   ```
2. Ein Login-Fenster erscheint. Klicken Sie auf **„Mit Netlify Identity anmelden"**.
3. Geben Sie Ihre E-Mail-Adresse und Ihr Passwort ein.
4. Nach erfolgreicher Anmeldung sehen Sie das CMS-Dashboard.

> **Tipp:** Sie erhalten Ihre Zugangsdaten per E-Mail vom Administrator (1. Vorsitzender).
> Beim ersten Login werden Sie aufgefordert, ein Passwort zu setzen.

---

## 2. Neuen Beitrag erstellen (Projekte & Aktionen)

Ein „Beitrag" ist alles, was Sie auf der Projekte-Seite veröffentlichen möchten –
z. B. ein Ausflug, ein Bastelfest oder ein neues Gerät.

### Schritt für Schritt:

1. Klicken Sie im linken Menü auf **„Projekte & Aktionen"**.
2. Klicken Sie oben rechts auf **„Neu erstellen"** (blauer Button).
3. Füllen Sie die Felder aus:

   | Feld | Pflicht | Hinweis |
   |------|---------|---------|
   | **Titel** | ✅ Ja | Kurzer, ansprechender Name der Aktion |
   | **Datum** | ✅ Ja | Datum der Aktion (nicht Veröffentlichungsdatum) |
   | **Titelbild** | Nein | Klicken Sie auf „Bild wählen" und laden Sie ein Foto hoch (JPG/PNG). Ohne Bild erscheint das Vereinslogo. |
   | **Teaser** | Nein | 2–3 Sätze für die Übersichtsseite (max. 200 Zeichen) |
   | **Inhalt** | ✅ Ja | Ausführlicher Text. Nutzen Sie die Formatierungsleiste für Überschriften, fetten Text usw. |

4. Klicken Sie oben rechts auf **„Speichern"** und dann auf **„Veröffentlichen"**.
5. Der Beitrag erscheint nach ca. 2–3 Minuten live auf der Website.

### Beiträge bearbeiten:
- Klicken Sie im Dashboard auf den Titel des Beitrags → Änderungen vornehmen → **„Speichern"** → **„Veröffentlichen"**.

### Beiträge löschen:
- Öffnen Sie den Beitrag → Klicken Sie oben auf das **„⋮"-Menü** → **„Löschen"**.
- Achtung: Das Löschen kann nicht rückgängig gemacht werden!

## 3. Dokumente im Downloadbereich austauschen

Verwenden Sie dies, um z. B. eine neue Satzung oder einen aktualisierten Aufnahmeantrag hochzuladen.

1. Klicken Sie im Menü auf **„Downloads"**.
2. Klicken Sie auf **„Download-Liste"**.
3. Sie sehen die Liste aller Download-Dokumente. Klicken Sie auf das Dokument, das Sie aktualisieren möchten.
4. Neben dem Feld „PDF-Datei" klicken Sie auf **„Datei wählen"**.
5. Wählen Sie die neue PDF-Datei von Ihrem Computer aus. Die alte wird ersetzt.
6. Klicken Sie auf **„Speichern"** und **„Veröffentlichen"**.

### Ein neues Dokument hinzufügen:
1. Scrollen Sie in der Liste nach unten und klicken Sie auf **„Hinzufügen"**.
2. Fügen Sie Bezeichnung, Beschreibung und PDF-Datei ein.
3. Speichern und veröffentlichen.

---

## 4. Vorstand aktualisieren

Wenn sich Vorstandsmitglieder ändern:

1. Klicken Sie auf **„Vorstand"** → **„Vorstandsmitglieder"**.
2. Bearbeiten Sie Name, Rolle, Bio oder Foto des jeweiligen Mitglieds.
3. **Speichern** und **Veröffentlichen**.

---

## 5. Sponsoren im Karussell verwalten

1. Klicken Sie auf **„Sponsoren-Karussell"** → **„Sponsorenliste"**.
2. Sponsoren können hinzugefügt, bearbeitet oder entfernt werden.
3. Für ein Logo: Klicken Sie auf „Logo" → Bild hochladen (PNG mit transparentem Hintergrund empfohlen, min. 200×80 px).

---

## 6. Häufige Fragen (FAQ)

**Wie lange dauert es, bis mein Beitrag live ist?**
Ca. 2–3 Minuten nach dem Veröffentlichen. GitHub baut die Seite automatisch neu.

**Ich sehe den Button „Veröffentlichen" nicht?**
Stellen Sie sicher, dass Sie den Beitrag zuerst gespeichert haben. Manchmal erscheint der Button erst danach.

**Das CMS lädt nicht?**
Prüfen Sie Ihre Internetverbindung. Versuchen Sie einen anderen Browser. Schreiben Sie dem Administrator.

**Kann ich Inhalte vorab vorbereiten ohne sofort zu veröffentlichen?**
Ja! „Speichern" speichert den Entwurf. „Veröffentlichen" macht ihn live. Sie können Entwürfe jederzeit weiterbearbeiten.

**Wer kann sich im CMS anmelden?**
Nur Personen, die vom Administrator eingeladen wurden. Einladungen erfolgen per E-Mail.
